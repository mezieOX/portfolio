# Mezie Portfolio

Next.js portfolio for Ikemma Augustine Chimezie (Senior Front-End / Mobile Engineer).

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

Images are served via `next/image` (AVIF/WebP) from optimized assets in `public/assets`.
